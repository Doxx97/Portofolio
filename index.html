Tentang Saya

Halo, perkenalkan nama saya Raihan Gusta, biasa dipanggil Gusta. Saya mahasiswa Universitas Negeri Malang jurusan Pendidikan Teknik Informatika dengan minat utama di bidang web development, khususnya front-end. Saya terbiasa membangun website dengan HTML, CSS, dan JavaScript, dan juga menggunakan framework Bootstrap untuk mempercepat pengembangan antarmuka.

Saat ini saya sedang memperdalam PHP dan Laravel untuk melengkapi kemampuan front-end saya dengan sisi back-end, supaya bisa membangun aplikasi web secara menyeluruh.
